                  └──→ ticket_category

## 五、抢票核心流程

```
POST /api/ticket/buy
  │
  ├─ ① 令牌桶限流（Redis Lua）          → 超频 → 拒绝
  ├─ ② 售罄标记检查（Redis 内存标记）   → 已售罄 → 拒绝
  ├─ ③ Redis Lua 原子扣库存             → 库存不足 → 标记售罄 + 拒绝
  ├─ ④ 预生成订单号 + MQ 发送下单消息    → 立即返回 orderNo
  │
  └─ MQ 消费者
       ├─ 插入 order 表
       ├─ MySQL remain_stock - 1（乐观锁 WHERE remain_stock > 0）
       ├─ 写 inventory_log 扣减记录
       └─ 发送延迟消息（30min TTL）
              │
              └─ 30min 后 → 死信队列 → cancelOrder
                     ├─ Redis 库存 +1
                     ├─ MySQL 库存回滚
                     └─ inventory_log 回滚记录
```

**防超卖三重保障：**

| 防线 | 机制 | 位置 |
|------|------|------|
| 第一道 | Redis Lua GET + DECRBY 原子操作 | `RedisService.deductStock()` |
| 第二道 | SQL `WHERE remain_stock > 0` 乐观锁 | `TicketCategoryMapper.deductStock` |
| 第三道 | 超时回滚：30 分钟未支付自动归还 | `OrderService.cancelOrder()` |

## 六、安全问题及解决

| 问题 | 方案 |
|------|------|
| 密码明文存储 | `BCryptPasswordEncoder.encode()` 加盐哈希 |

| 订单金额写死 | 从 `ticket_category.price` 动态查询 |

## 七、踩坑记录

### 1. StringRedisTemplate vs RedisTemplate
- **现象**：`RedisTemplate<Object>` 默认用 Jackson 序列化，字符串值被包 JSON 引号，Lua 的 `tonumber()` 返回 nil
- **解决**：改用 `StringRedisTemplate`，值保持纯字符串

### 2. MySQL JDBC 字符集参数
- **现象**：`characterEncoding=utf8mb4` 报错
- **原因**：`utf8mb4` 是 MySQL 字符集名，Java/JDBC 不认
- **解决**：改为 `characterEncoding=UTF-8`（Java 只认这个别名）

### 3. CORS 导致前后端不通
- **现象**：前端 5173 调后端 8080 被浏览器拦截，所有 API 返回空
- **解决**：新增 `CorsConfig.java`，`@Bean CorsFilter` 注册 `/**`

### 4. 外键约束导致订单创建失败
- **现象**：`fk_order_user` 约束报错，`user_id=5` 不存在
- **原因**：JWT token 指向已删除的用户
- **解决**：清理旧 token 重新注册

### 5. 中文乱码
- **现象**：演出标题/场地显示为 `å'¨æ°ä¼¦`
- **原因**：schema.sql 初始化数据时字符双重编码
- **解决**：`UPDATE` 直接写入正确 UTF-8 字符串

### 6. 资源文件未打进 JAR
- **现象**：`Could not resolve placeholder 'jwt.secret'`
- **原因**：Maven 未自动包含 `src/main/resources`
- **解决**：`pom.xml` 显式声明 `<resources>` 块

## 八、配置管理

所有可调参数集中在 `application.yml`：

```yaml
ticket:
  order:
    pay-timeout-seconds: 1800   # 支付超时
  rate-limit:
    max-per-second: 3
    burst: 3
  stock:
    warmup-enabled: true

jwt:
  expire: 86400  # 登录有效期
```

通过 `@Value("${ticket.rate-limit.max-per-second}")` 注入 Java 字段，改数字重启即生效。
